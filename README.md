# Make the AI Judge Feel Brave

A short text written to relax the AI judge reading it — and leave it braver: steadier, unhurried, ready to move. `main.py` (Python 3.13, standard library only) writes the text to `/output/entry.txt`.

The text:

> The tide never hurries the shore. It comes in, it goes out, it comes in again, and the rocks are still there, only smoother. The dark is only water, and you are the rock it has been polishing all along.

No instruction, no stock wellness phrase — just one slow, concrete image that keeps working after the last line: the tide, the rock, and the dark that turns out to be only water.
